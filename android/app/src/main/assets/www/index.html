⌁ ESP32 Claude

Per WLAN verbinden

Handy und ESP32 im selben WLAN – oder mit dem Hotspot ESP32-Claude (Passwort esp32code) verbinden, IP dann 192.168.4.1.

Per Bluetooth verbinden

Der ESP32 erscheint als ESP32-Claude (oder dem Namen, den du vergeben hast).

Per USB-Kabel (OTG) verbinden

ESP32 direkt per USB-C/OTG-Kabel ans Handy stecken. Funktioniert auch, wenn noch kein Agent drauf ist.

Agent auf ESP32 installieren

Voraussetzung: MicroPython ist bereits geflasht (siehe Anleitung im Projekt). Danach ist der ESP32 per WLAN und Bluetooth erreichbar.

Gerät

Noch keine Verbindung.

WLAN des ESP32 ändern

Schickt neue WLAN-Daten über die aktuelle Verbindung (z. B. per Bluetooth oder Hotspot) – danach startet der ESP32 neu.

Einstellungen (API-Key, Modell, Board)

Bekommst du unter console.anthropic.com → API Keys. Wird nur auf diesem Handy gespeichert.
